# Planet Earth · Three.js

Continents, oceans, ice, city lights and clouds, with zero image textures.

**Live demo:** https://ankit-alpha-q.github.io/threejs-procedural-earth/

Built step by step on the MahaDev YouTube channel. Everything is in [`earth.js`](./earth.js).

## Run it
Any static server works, for example:
```
npx serve .
```

## Make it yours
- More land: 0.53 → 0.48
- A frozen world: ice from 0.75 → 0.3
- Mars: swap the ocean and land colors for reds
